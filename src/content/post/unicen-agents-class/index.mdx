## Four takeaways

1. Decide first whether the problem needs an agent at all. If it can be solved deterministically, solve it deterministically.
2. Start with the simplest architecture that works, and add complexity only when the problem asks for it.
3. Evaluation, observability and monitoring are the pillars. They are what separates a good agentic system from an average one.
4. Build it so it can scale to real users in production, in a controlled way.
